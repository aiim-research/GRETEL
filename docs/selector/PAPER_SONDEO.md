# Selector paper: the sondeo (generation 2 of the arms), fold 0 of every cell

Generated by `scripts/gen_selector_paper_matrix.py` (its docstring gives the arms and the order). Datasets proteins, synthie, bbbp, aids, colors-3, bzr, enzymes with the first paper's oracle, the margin oracle (τ = 0.7) and the robust one (edge perturbations {'drop': 0.1, 'add': 0.1}); and tri (tri-40, tri-40n, tri-80) with its exact rule and the three oracles on a GCN. colors-3 on 20 fixed instances per fold (40 on the collection folds). The arms carry the configuration decided after the first sondeo (`ANALISIS_SONDEO.md`, section 5) and new names, so everything but bls_v0 runs again; the first sondeo's results stay under their old scopes. What already has results in git is skipped.

Rule: on the server only Slurm jobs compute (nothing heavy on the login node), and at most 10 jobs at a time. Each step starts once `squeue -u $USER` shows nothing left of the previous one. No cache job is needed: the margin oracles wrap the committed base oracles, and the robust ones are committed.

**Step 0. Sync** (only git and the pinned environment):

```bash
cd ~/projects/GRETEL
launchers/server_sync.sh
conda activate GRTL
```

**Step 1. Queue A**: the collections of folds 1 and 2, bls_v0 and bls_v1 on fold 0 (132 configs, 10 at a time; the bls_v0 configs that already have results are skipped):

```bash
launchers/slurm_submit.sh -p normal -m 10 docs/selector/PAPER_SONDEO_A.md
squeue -u $USER
grep -lE "exit status [1-9]|Traceback" output/logs/*/*/*_<job>_*.out     # <job>: the array job number slurm_submit printed
```

A queue that ends with failures can be submitted again as it is: finished configs are skipped.

**Step 2. Pretraining** of the selector checkpoints from those collections (1 job, both folds of every cell):

```bash
sbatch -p normal launchers/slurm_pretrain.sh proteins proteins-m70 proteins-rob synthie synthie-m70 synthie-rob bbbp bbbp-m70 bbbp-rob aids aids-m70 aids-rob colors-3-s20 colors-3-m70-s20 colors-3-rob-s20 bzr bzr-m70 bzr-rob enzymes enzymes-m70 enzymes-rob tri-40 tri-40-gcn tri-40-gcn-m70 tri-40-gcn-rob tri-40n tri-40n-gcn tri-40n-gcn-m70 tri-40n-gcn-rob tri-80 tri-80-gcn tri-80-gcn-m70 tri-80-gcn-rob
squeue -u $USER
tail output/slurm/pretrain_<job>.out     # ends with: built N checkpoint(s); collections still missing: none
```

**Step 3. Queue B**: selector_v1 on fold 0 (33 configs):

```bash
launchers/slurm_submit.sh -p normal -m 10 docs/selector/PAPER_SONDEO_B.md
squeue -u $USER
```

**Step 4. Back home** (local machine): `make server-import`, then commit the results, logs, checkpoints and new caches, and `python scripts/sondeo_summary.py` for the table.
