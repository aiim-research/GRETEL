# Selector paper: the sondeo, fold 0 of every dataset with every oracle

Generated by `scripts/gen_selector_paper_matrix.py` (its docstring gives the order and the arms). Datasets proteins, synthie, bbbp, aids, colors-3, bzr, enzymes with the first paper's oracle, the margin oracle (τ = 0.9) and the robust one (edge perturbations {'drop': 0.1, 'add': 0.1}); and tri (tri-40, tri-40n, tri-80) with its exact rule and the three oracles on a GCN. colors-3 on 20 fixed fold-0 instances. bbbp's original-oracle fold 0 runs locally. What already has results in git is skipped.

Rule: on the server only Slurm jobs compute (nothing heavy on the login node), and at most 10 jobs at a time. Each step starts once `squeue -u $USER` shows nothing left of the previous one.

**Step 0. Sync** (only git and the pinned environment):

```bash
cd ~/projects/GRETEL
launchers/server_sync.sh
conda activate GRTL
```

**Step 1. Caches: ENZYMES' dataset and oracle, and the robust oracles** (7 jobs):

```bash
G=lab/config/generate_minimize
for t in enzymes proteins-rob synthie-rob bbbp-rob aids-rob colors-3-rob enzymes-rob; do sbatch -p normal launchers/slurm_warm.sh $G/$t/dce/dce-lcls/generate_minimize0.jsonc; done
squeue -u $USER
grep -L "exit status 0" output/slurm/warm_<job>.out     # for each job number sbatch printed: a file listed here failed
```

**Step 2. Queue A**: the collection of fold 1 (the training data of the fold-0 checkpoint), bls_v0 and bls_v1 on fold 0 (94 configs, 10 at a time):

```bash
launchers/slurm_submit.sh -p normal -m 10 docs/selector/PAPER_SONDEO_A.md
squeue -u $USER
grep -lE "exit status [1-9]|Traceback" output/logs/*/*/*_<job>_*.out     # <job>: the array job number slurm_submit printed
```

A queue that ends with failures can be submitted again as it is: finished configs are skipped.

**Step 3. Pretraining** of the selector checkpoints from those collections (1 job):

```bash
sbatch -p normal launchers/slurm_pretrain.sh proteins synthie aids bzr enzymes proteins-m90 synthie-m90 bbbp-m90 aids-m90 colors-3-m90-s20 bzr-m90 enzymes-m90 proteins-rob synthie-rob bbbp-rob aids-rob colors-3-rob-s20 bzr-rob enzymes-rob tri-40 tri-40-gcn tri-40-gcn-m90 tri-40-gcn-rob tri-40n tri-40n-gcn tri-40n-gcn-m90 tri-40n-gcn-rob tri-80 tri-80-gcn tri-80-gcn-m90 tri-80-gcn-rob
squeue -u $USER
tail output/slurm/pretrain_<job>.out     # ends with: built N checkpoint(s); the missing collections listed are the fold-2 ones, which the sondeo does not run
```

**Step 4. Queue B**: selector_v1 on fold 0 (31 configs):

```bash
launchers/slurm_submit.sh -p normal -m 10 docs/selector/PAPER_SONDEO_B.md
squeue -u $USER
```

**Step 5. Back home** (local machine): `make server-import`, then commit the results, logs, collections, checkpoints and new caches.
