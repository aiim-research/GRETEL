# Thesis experiments and the configurations that reproduce them

The LBS thesis states that "todas las configuraciones experimentales se publican para su replicación". This page is that publication: every experiment in its results chapter, mapped to the configuration directory that produces it.

**Thesis.** *Búsqueda Local Acotada para la Minimización de Explicaciones Contrafactuales en Grafos*, Rodrigo García Gómez. BLS in the thesis is LBS elsewhere in this repository, and `lcls` in the configuration tree: the three names are the same algorithm (`src/explainer/future/metaheuristic/local_search/local_search.py`).

Names line up as follows.

| Thesis | Configuration tree | Class |
|---|---|---|
| BLS | `lcls` | `metaheuristic.local_search.local_search.LocalSearch` |
| OBS-min | `obs` | `meta.minimizer.obs.OBS` |
| generator alone (no minimisation) | `dummy` | `meta.minimizer.dummy.Dummy` |
| DCEM | `dcm` | `search.dcm.DCM` |
| DCE, OFS, RSGG, DFS | `dce`, `ofs`, `rsgg`, `dfs` | `search.dces`, `search.ofs`, `generative.rsgg`, `search.dfs` |
| BLS + selector, trained | `lcls-net-trainable` | `local_search_selection_net_trainable.LocalSearch` |
| DDBS | `dfs` + `dbs` | the decoupled pair, recombined |

Every path below is `lab/config/generate_minimize/<dataset>/<generator>/<generator>-<variant>/generate_minimize<fold>.jsonc`, ten folds each (0 to 9).

## Experimental setup (Section 5.1)

Nine datasets: `tcr-tco-300` (TCR), `synthie`, `asd`, `bbbp`, `enzymes`, `bzr`, `proteins`, `aids`, `colors-3`. The four TU datasets download on first use, the rest are generated or ship with the repository.

All datasets are preprocessed with the padding manipulator, which is what makes the cell-wise GED comparable across graphs of different sizes. It is applied through `compose_man` pointing at `lab/config/snippets/datasets/padding.json`, so it is already in every config below.

Metrics: Correctness, Oracle Calls, GED and FED, declared by `lab/config/snippets/default_pipeline.json`.

## Main results, PI1 to PI3 (Section 5.2)

BLS against OBS-min across three generators and four datasets, plus the generator alone as the baseline bar.

```
lab/config/generate_minimize/{asd,tcr-tco-300,bbbp,synthie}/{dce,ofs,rsgg}/{dce,ofs,rsgg}-{dummy,lcls,obs}
```

36 cells. Table 5.2 (Synthie) is the `synthie` slice. Figures 5.1 to 5.3 are the per-generator bar charts, regenerated by `python scripts/make_paper_figures.py`.

## PI4: oracle-call budget (Section 5.3, Table `tab:abloc`)

Synthie under six budgets, both minimizers. The budget lives in the minimizer's `max_oracle_calls`, and each budget has its own generator-level directory:

| Thesis row | Directory | `max_oracle_calls` |
|---|---|---|
| Synthie-2.5k | `synthie/dce-2.5/dce-{lcls,obs}` | 2500 |
| Synthie-5k | `synthie/dce-5/dce-{lcls,obs}` | 5000 |
| Synthie-7.5k | `synthie/dce-7.5/dce-{lcls,obs}` | 7500 |
| Synthie-10k | `synthie/dce-10/dce-{lcls,obs}` | 10000 |
| Synthie-15k | `synthie/dce-15/dce-{lcls,obs}` | 15000 |
| Synthie-20k | `synthie/dce-20/dce-{lcls,obs}` | 20000 |

Reading the numbers: the reported oracle calls sum generator and minimizer while the budget caps only the minimizer, and the cap is per instance while the table averages over the test set. Both points are explained in the thesis text.

## PI5: attribute manipulation (Section 5.3, Tables `tab:attributes-*`)

The "no attr" and "attr" columns are the same dataset and the same oracle, differing only in the minimizer's `attributed` flag. The configuration tree encodes that as two dataset directories:

| Thesis column | Directory | `attributed` |
|---|---|---|
| Synthie, attr | `synthie/{ofs,dce,rsgg}/*-lcls` | `true` |
| Synthie, no attr | `synthie-no-att/{ofs,dce,rsgg}/*-lcls` | `false` |
| BBBP, attr | `bbbp/{ofs,dce,rsgg}/*-lcls` | `true` |
| BBBP, no attr | `bbbp-no-attr/{ofs,dce,rsgg}/*-lcls` | `false` |

## PI6: neighbourhood design (Section 5.3, Table `tab:comparison-variants`)

Full BLS against two restricted variants, on four datasets with DCE:

```
lab/config/generate_minimize/{bbbp,synthie,tcr-tco-300,asd}/dce/dce-{lcls,lcls-var-1,lcls-var-2}
```

`lcls-var-1` keeps only the deletion strategies (1a and 1b), `lcls-var-2` only swap and add. Two further variants exist in the tree, `lcls-var-3` and `lcls-var-4`, which permute the priority order rather than removing a strategy. They belong to the paper revision (E3), not to the thesis.

## DCEM (Section 5.4, Tables `tab:all-datasets-dce` and `tab:all-datasets-dcem`)

```
lab/config/generate_minimize/{synthie,bbbp,enzymes,bzr,aids,proteins,colors-3}/{dce,dcm}/{dce,dcm}-{dummy,lcls,obs}
```

**Run `scripts/compute_dcm.py` once per dataset before any `dcm` configuration.** DCEM loads a pre-trained medoid artefact rather than computing it per run, and that is the whole point of the method: generator-side oracle complexity becomes constant in the dataset size. The artefacts for the paper's datasets are versioned, so those runs will log `Loading: DCM-...`.

## Selector model (Section 5.5)

BLS with the selector network against plain BLS, for DCE and DCEM:

```
lab/config/generate_minimize/<dataset>/{dce,dcm}/{dce,dcm}-lcls-net-trainable
lab/config/bls_selection_net/            # the selector study, untrained variant
lab/config/bls_selection_net_trainable/  # trained variant
```

These need the shared LST artefact as well: `python scripts/compute_lst_methods.py --do-pair <pair>` once per dataset.

## Coverage

Checked mechanically: the 140 (experiment, dataset, generator, variant) cells listed above all exist with their full ten folds, as do the twelve budget-ablation cells of PI4. Nothing in the results chapter lacks a configuration.

The thesis gives no literal run commands, so there is nothing to match verbatim. Everything above runs the same way:

```bash
python main.py lab/config/generate_minimize/synthie/dce/dce-lcls/generate_minimize0.jsonc 1
```

or in bulk through `scripts/run_experiments.py`. See [reproducing-experiments.md](reproducing-experiments.md).

## Related doctoral thesis

*Counterfactual Explainability in Graphs: Foundations, Generative Methods, and Ensemble Techniques*, Mario Alfonso Prado Romero, Gran Sasso Science Institute, 7 March 2025. Handle: [20.500.12571/34884](https://iris.gssi.it/handle/20.500.12571/34884). The record carries no attached file, so the full text is not currently downloadable from the repository.
